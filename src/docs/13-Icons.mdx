# Иконки

Линейные, 24×24, толщина 1.3, цвет наследуется (`currentColor`). Экспортированы из Figma (ui-icons).

<IconGallery />

- `chevron-up-down` — селектор значения в поле; `chevron-up` / `chevron-down` — раскрытие строк.
- Иконка в кнопке всегда имеет подпись: текст кнопки или `label` у `IconButton`.
- Погодные иконки и флаги стран — в Figma, в код добавляются по мере надобности.
